01 / CONTEXT

Overview

This was my digital-design onboarding project for UWASIC, Waterloo’s chip design team: a Verilog SPI Mode 0 peripheral that drives PWM outputs. It took one design from RTL, through automated simulation, to a generated chip layout.

02 / CONTRIBUTION

The work

The peripheral

The peripheral has five registers and sixteen outputs, configured over SPI Mode 0. Two-stage clock-domain crossing (CDC) moves signals safely between clock domains.

  • Verilog RTL for the SPI interface and output controls.
  • A register interface for configuring the outputs and the PWM.
  • Two-stage CDC for signals crossing clock domains.

Verification

I wrote Python/cocotb tests, simulated with Icarus Verilog, that check the 3 kHz PWM at 0%, 50%, and 100% duty cycle, along with the output-enable behavior.

From RTL to GDS

I configured Tiny Tapeout and GitHub Actions to run the simulation tests and generate the GDS layout files automatically.

03 / REFLECTION

Outcome

The peripheral is complete, with automated simulation tests and GDS generation. It gave me the foundation for the functional-unit control RTL I later wrote for UWASIC’s ray-tracing ASIC.
