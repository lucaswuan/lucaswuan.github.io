01 / CONTEXT

Overview

I built a C++ path tracer using the framework from Ray Tracing in One Weekend. This was a learning project focused on understanding how geometric intersections and repeated light sampling turn a scene into an image.

02 / CONTRIBUTION

The work

Geometry & intersections

I implemented parametric rays, ray-sphere intersections, and surface normals. These establish where a ray meets the scene and the orientation of the surface at that point.

Shading & sampling

I implemented Monte Carlo diffuse shading and multisample anti-aliasing to render spheres with smoother edges and reduced image noise.

Quality versus rendering time

I analyzed how samples per pixel affect image noise and rendering time. This made sampling a practical trade-off to investigate as well as a part of the rendering algorithm.

03 / REFLECTION

Outcome

Built a working C++ path tracer and explored the relationship between geometry, shading, sampling, and image quality. The implementation follows the educational framework of Ray Tracing in One Weekend.
