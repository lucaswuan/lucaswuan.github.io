01 / Context

Overview

SignEd is an ASL learning website we built at Hack the Bias, a hackathon with 101 participants, where it won first place in the Beginner Tier. As the sole programmer on our five-person team, I developed the application using Python, Flask, JavaScript, and HTML/CSS, connecting computer vision to an interactive learning experience.

02 / Contribution

The work

Recognizing a sign

MediaPipe and OpenCV provide the hand-tracking pipeline. I normalized 21 three-dimensional hand landmarks by wrist position and hand size, then used distance-weighted K-nearest neighbors to recognize all 24 static letters of the ASL alphabet. J and Z are left out because they are signed with motion.

Connecting recognition to learning

Live recognition feedback is connected to guided lessons. A learner unlocks progression after holding the correct sign for three seconds, connecting the recognition result to a clear practice goal.

My contribution

  • Implemented the Python/Flask application and the browser interface.
  • Built the hand-landmark normalization and pose-classification pipeline.
  • Connected live feedback to lesson progression.

03 / Reflection

Outcome

SignEd won first place in the Beginner Tier at Hack the Bias. The project brought together computer vision, a web interface, and guided practice in one ASL learning experience.
