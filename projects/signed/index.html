01 / CONTEXT

Overview

SignEd is an ASL learning website built for Hack the Bias. As the team’s sole programmer, I developed the application using Python, Flask, JavaScript, and HTML/CSS, connecting computer vision to an interactive learning experience.

02 / CONTRIBUTION

The work

Recognizing a sign

MediaPipe and OpenCV provide the hand-tracking pipeline. I normalized 21 three-dimensional hand landmarks by wrist position and hand size, then used distance-weighted K-nearest neighbors to recognize ASL poses.

Connecting recognition to learning

Live recognition feedback is connected to guided lessons. A learner unlocks progression after holding the correct sign for three seconds, connecting the recognition result to a clear practice goal.

My contribution

  • Implemented the Python/Flask application and the browser interface.
  • Built the hand-landmark normalization and pose-classification pipeline.
  • Connected live feedback to lesson progression.

03 / REFLECTION

Outcome

SignEd won the Beginner Track at Hack the Bias. The project brought together computer vision, a web interface, and guided practice in one ASL learning experience.
